Política de Privacidade – Início TV

Última atualização: 24 de outubro de 2026.

Início TV é um app de uso pessoal, instalado apenas na TV do próprio autor.

Dados acessados

Com a autorização da conta Google, o app lê, somente para exibição na tela da TV: as tarefas do Google Tasks e os vídeos marcados como “gostei” no YouTube.

Uso e armazenamento

Os dados são usados apenas para mostrar essas informações na TV. Ficam guardados somente no próprio aparelho. Não são enviados a servidores do autor, não são vendidos nem compartilhados com terceiros e não são usados para publicidade.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Desinstalar o app apaga todos os dados guardados na TV.
